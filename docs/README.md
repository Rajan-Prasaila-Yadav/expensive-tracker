## 🚀 Quick Start Guide

### 1. Backend (Django 5 + Prisma + PostgreSQL)
```bash
# In project root
.\backend\venv\Scripts\python backend/manage.py runserver 0.0.0.0:8000
```

### 2. Frontend (React 19 + Vite)
```bash
cd frontend
npm run dev
```

### 3. Production Build Validation
```bash
cd frontend
npm run build
```
